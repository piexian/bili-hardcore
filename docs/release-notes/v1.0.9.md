### ✨ 新功能

- **新增 JEV (TypeSafe) 预设**：JEV 是 TypeSafe 的 System One 决策模型，不生成文本、直接返回结构化决策。程序会用其 `choice` 原语作答，答题界面同步显示模型版本、置信度与各选项概率。接口地址以 `/systemone` 结尾时自动使用该协议，中转地址同样可用
- **新增 Grok (xAI) 预设**：自动识别 xAI 的推理强度参数，兼容中转服务
- **新增 agent skill**：装上后对任意支持该约定的 AI 编程助手说「帮我答硬核会员」即可触发，由 agent 自身作答

#### 🔄 变更

- 配置页的 API URL 去掉 OpenAI 限定；选用 JEV 时「思考模式」开关标注为不适用
- 发布页与一键安装脚本改为跟随实际发布仓库，从 fork 发布时不再指向上游而拿不到产物

### 🐛 修复

- 修复部分服务商返回非流式 JSON 响应时无法解析出答案的问题
- 修复 SSE 响应被拆分在多个数据块时探测失败的问题
- 修复 Grok 请求在部分参数组合下报错的问题
